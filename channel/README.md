# Канал обновлений «Умного Вызов»

Приложение проверяет стабильный JSON и публичный GitHub-релиз **без токена**:

```
https://raw.githubusercontent.com/UMEDJON12/umnyj-vyzov-updates/main/updates/stable.json
https://api.github.com/repos/UMEDJON12/umnyj-vyzov-updates/releases/latest
```

## Как публиковать версию

1. Соберите и проверьте APK (`sh tests/run_all.sh`).
2. Создайте **обычный (опубликованный)** релиз с тегом `vX.Y.Z` и приложите APK.
   Черновики и предрелизы канал не принимает.
3. Событие `release: published` запускает workflow
   `.github/workflows/publish-stable.yml`: скрипт `channel/publish_stable.py`
   скачивает APK, проверяет размер, SHA-256, пакет, versionCode и **оригинальный
   сертификат подписи**, а затем записывает `updates/stable.json` коммитом
   (без force-push; параллельные запуски сериализованы concurrency-группой).
4. Если версия не новее уже опубликованной — публикация отклоняется
   (защита от отката). Повторный запуск для той же версии идемпотентен.

## Что видит приложение

- автопроверка при открытии приложения (можно отключить в настройках);
- диалог «Доступно новое обновление» с кратким описанием и кнопками
  «Позже» / «Скачать»; «Позже» скрывает уведомление до следующей версии;
- загрузка с процентами, объёмами и отменой в фоновом уведомлении;
- повторная проверка релиза после скачивания и только затем системный
  установщик.

## Локальная проверка скрипта

```bash
python3 -m unittest discover -s tests/channel -v
```
