# GitHub Actions — Умный Вызов 2.3.10

Данная ветка содержит **открытый исходный код без закрытых ключей** и сборочный workflow. При push в ветку `release-candidate/2.3.10` GitHub Actions компилирует неподписанный APK, прогоняет тесты, проверяет готовый подписанный владельцем APK и создаёт **черновик** v2.3.10.

Почему готовый подписанный APK лежит в `ci/`? Закрытый ключ нельзя публиковать в публичном репозитории. Подписанная сборка сделана из того же исходного проекта в закрытом окружении с оригинальным ключом. На GitHub компилируется unsigned артефакт для проверки исходников; CI не подписывает файл и не владеет ключом.

После **ручной** публикации черновика GitHub Actions default-ветки `main` выполняет `release:published` и обновляет `updates/stable.json`. Пока релиз черновик, пользователи не видят обновления. Срабатывание зависит от интернет-доступа и настроек автопроверки в приложении; принудительная установка не производится.

Полный приватный архив с ключами/паролями владельцу передан отдельно. Не загружать его или содержимое папки `keys/` в открытый GitHub.
