# Умный Вызов 2.3.11 — тестовый кандидат

Для сборки используется GitHub Actions с кодом из `sources/Umnyj_Vyzov_v2.3.11_Public_Source.zip`. Архив содержит незашифрованные Java-исходники и тесты, но НЕ содержит закрытых ключей. `ci/SmartCall-2.3.11-signed.apk` подписан локально исходным сертификатом приложения; CI проверяет его совпадение с собранным кодом и подпись.

Изменения: на Android 11+ вместо перехода на новый экран загрузки открывается модальное окно с процентом, прогрессом, скачанным и оставшимся объёмом; кнопки «Позже» и «Скачать» имеют фиксированный визуальный порядок; добавлена диагностика события клавиш и конфликтующих AccessibilityService.

Ограничение: на Xiaomi Android 16 служба может НЕ получать аппаратные события, если они принадлежат другому экранному диктору. Этот кандидат НЕ подтверждён на реальном устройстве. Сведения об изменении громкости НЕ используются для ответа на звонок во избежание случайных ответов.

Релиз создаётся как **Draft**. Публикация и обновление стабильного канала — только после проверки пользователем.
