# Умный Вызов — тестовая версия 2.3.12

Сборка через GitHub Actions из `sources/Umnyj_Vyzov_v2.3.12_Public_Source.zip`. Архив содержит открытые Java-исходники и хостовые тесты без паролей и закрытых ключей.

Команда сборки: `python3 build_apk.py --unsigned --output dist/SmartCall-2.3.12-CI-unsigned.apk`.

GitHub Actions проверяет, что содержимое собранного APK **побайтово совпадает** с подписанным владельцем `ci/SmartCall-2.3.12-signed.apk`; затем проверяет сертификат и хостовые тесты. GitHub не хранит закрытый ключ подписи.

Черновик 2.3.12 создаётся только после успешных проверок. **Публикация запрещена до испытания на Xiaomi 2602BPC18G, Android 16.**

Особенности и диагностика находятся в `DIAGNOSTIC_2312.md` внутри публичного исходного архива.

Ограничение Android: фильтрация аппаратных клавиш через AccessibilityService может принадлежать другому экранному диктору; при отсутствии события на Android 16 приложение не может ответить кнопкой через разрешённые публичные API. Никаких ложных ответов на изменение уровня громкости не реализовано.
