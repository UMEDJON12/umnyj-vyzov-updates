# Умный Вызов — тестовая версия 2.3.13

Обновление из 2.3.12, `versionCode=36`, `com.smartcall.ru`.

Публичный Java-проект находится в `sources/Umnyj_Vyzov_v2.3.13_Public_Source.zip`, подписанный экземпляр `ci/SmartCall-2.3.13-signed.apk`. Персональные исходные ключи находятся только у владельца, в публичных файлах запрещены.

GitHub Actions собирает неподписанный APK из этого исходного кода, выполняет сравнительную проверку содержимого DEX/ресурсов подписанного APK, проверяет оригинальный сертификат подписи и хостовые тесты, затем создаёт **Draft**, не публикуя его.

Исправления: одноразовое разрешение на завершение звонка только после разрешённой клавиши; удалены опасные резервные сбросы; подписочный TelephonyCallback для Android 12+, сохранённый журнал SIM; только подтверждённый RINGING разрешает ответ на физическое ACTION_UP без DOWN.

**Важно:** реальный Xiaomi 2602BPC18G с Android 16 не тестировался. Самопроизвольные сбросы могут иметь системную или сетевую причину. Публиковать черновик нельзя до проверки пользователем.

**Обнаруженный риск старых архивов:** исторические тестовые fixture-файлы могли содержать ключ подписи. В данном публичном ZIP любые такие файлы удалены; владельцу нужно отдельно оценить предыдущие загруженные материалы.
